# Movies & Entertainment

A responsive movie-discovery MVP built with Next.js, TypeScript and Tailwind-free custom CSS.

## Included

- Dark Netflix-inspired homepage with featured title and content rows
- Movie details pages with Telegram download CTA
- Search/browse page and category filters
- Responsive layouts for mobile and desktop
- Local sample catalogue — ready to replace with TMDb and Supabase

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
